# Tic Tac Toe

A browser-based Tic Tac Toe game built as part of The Odin Project JavaScript curriculum.

## Features

* Two-player Tic Tac Toe game
* Players can enter their names
* X and O turns are handled automatically
* Prevents players from selecting occupied cells
* Detects horizontal, vertical, and diagonal wins
* Detects ties
* Start and restart functionality
* Responsive and simple interface

## Technologies Used

* HTML
* CSS
* JavaScript
* DOM Manipulation
* JavaScript Factory Functions
* JavaScript IIFE / Module Pattern

## How to Play

1. Enter a name for each player.
2. Click **Start Game**.
3. Player 1 starts with X.
4. Players take turns selecting an empty square.
5. The first player to get three marks in a row wins.
6. If all nine squares are filled without a winner, the game ends in a tie.
7. Click **Restart Game** to play again.
